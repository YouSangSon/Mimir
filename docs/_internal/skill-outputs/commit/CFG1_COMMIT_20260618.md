## 커밋 메시지

fix(config): sources.yaml CLI 검증 통일

- `mimir.config.load_validated_sources_config()`가 raw 설정과 parsed `SourcesConfig`를 함께 반환해, CLI마다 반복하던 `sources.yaml` 검증 경로를 하나로 정리
- `analyze`, `deliver`, `dashboard`가 설정 오타를 실행 전에 잡아 `[mimir] invalid sources.yaml:` 메시지와 exit code 1로 실패하도록 보강
- `deliver`와 `dashboard`는 malformed config에서 report/dashboard 파일을 쓰지 않도록 막아, 잘못된 설정이 출력물 생성으로 이어지지 않게 고정
- `collect`, `run`, `backfill`은 helper를 쓰되 runtime `ValidationError`를 설정 오류로 오분류하지 않도록 좁은 catch 범위 유지
- malformed config 회귀 테스트 3개와 문서 추적을 추가하고 전체 495개 테스트와 98% coverage로 검증
